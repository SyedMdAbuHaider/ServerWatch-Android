# ServerWatch Android

Production-oriented Android server monitoring client with a lightweight Linux agent.

## Planned components

- Android app: Kotlin + Jetpack Compose
- Linux monitoring agent: Go
- Monitoring API: FastAPI
- Metrics: Prometheus-compatible
- Push notifications: Firebase Cloud Messaging
- Optional Telegram alerts
- Docker and systemd health monitoring

## Build

The repository includes a GitHub Actions workflow for assembling the release APK.

## Status

Initial production foundation.
